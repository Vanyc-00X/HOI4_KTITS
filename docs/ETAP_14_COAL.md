# Этап 14 — уголь (HOI4 1.19)

Версия мода: **0.13.0**

## Зачем

Целевая версия игры — **HOI4 1.19.\***, где в бесплатном обновлении вместе с
*No Compromise, No Surrender* появился **уголь (coal)** — ресурс энергии для
фабрик (Power Plant / энергопотребление). Ваниль определяет его в
`common/resources/00_resources.txt` (icon frame 7) и раздаёт по ванильным
штатам.

Мод заменяет `history/states` через `replace_path`, поэтому ванильный уголь
на нашу карту не попадает — его нужно выдавать самим в файлах штатов.

## Формат (проверено на ванильных/актуальных модах 1.19)

Уголь — обычный ресурс штата, просто седьмая строка в блоке:

```text
state={
	id=1
	...
	resources={
		steel=18
		...
		chromium=4
		coal=39
	}
	history={ ... }
}
```

Дополнительные файлы (`common/resources`, спрайты, `interface`) **не нужны**:
`coal` уже есть в базовой игре, локализация и иконки — ванильные.

## Что сделано

- `tools/build_resources.py`: профили 24 тегов дополнены седьмым значением —
  углём; уголь считается отдельной формулой (не сдвигает bias остальных шести
  ресурсов), столицы 1–24 получают +6, минимум по штату — 6.
- Перегенерированы все **127 штатов**: у каждого есть `coal` (в сумме 3060,
  по штатам 9–52; у каждой страны ≥ 47).
- `tools/add_coal_focus_rewards.py`: 78 фокусов-наград `add_resource = { type =
  steel ... }` получили парный грант угля (×1.5, минимум 4) — 54×12 и 24×15.
- `tools/validate_mod.py`: проверка блока `resources` — известные ключи и
  наличие всех 7 ресурсов, включая `coal`.
