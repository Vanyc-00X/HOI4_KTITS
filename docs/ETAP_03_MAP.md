# Этап 3 — Карта «Казуалия»

## Итог
Сгенерирована компактная вымышленная карта XXI века со **всеми 24 государствами** на одном суперконтиненте.

| Параметр | Значение |
|----------|----------|
| Размер | **2048×1024** (world_normal 1024×512) |
| States | **127** (столицы 1–24 сохранены) |
| Land provinces | **1012** |
| Sea provinces | **1036** |
| Strategic regions | **43** (24 суша + 19 морей) |
| Генератор | `tools/generate_kazualia_map.py` |

## Расположение (макрорегионы)

```
        [СЕВЕР: SVA —— CLB —— ART]
              |         |       |
[СЗ: KMS]—[ZLD]—[VCI CORE]—[NBL]—[СВ: ZNS]
              |    |    |    |
         [MUS] [SOY] [FDP] [DMK]
              |    |    |    |
[З: ISL]—[TRF]—[ZML]—[ISG]—[HRL]—[В: KRZ]
              |              |
         [ADL]          [CRE]—[BTR]
              |              |
        [ЮЗ: ZKR]——[SHF]——[ЮВ: KZS]
```

## States на страну
- Крупные (VCI, KRZ, SHF): **10**
- Средние: **5**
- Малые (KZS, ADL, ZML, ISG): **3**

Столицы = state ID **1–24** (как в Этапе 2).

## Рельеф и реки
- Провинции получили игровые типы местности: равнины/степи (`plains`), холмы, горы, леса, болота и пустыня.
- Горный хребет и окружающие холмы проходят диагональю через материк; леса, низины и сухие земли занимают отдельные регионы.
- Высоты `heightmap.bmp` согласованы с рельефом, а `rivers.bmp` использует индексированные сегменты рек HOI4.
- Между столицами соседних стран проложены железнодорожные линии; стартовые узлы снабжения имеют уровень по размеру державы.
- Стартовые армии теперь соответствуют размеру державы: 6 дивизий у крупных, 4 у средних и 2 у малых стран.
- У каждой державы собственный шаблон армии и командир; кавалерийские, артиллерийские и моторизованные части опираются на стартовые технологии и запасы техники.
- В решениях доступно обострение пограничного кризиса, а bookmark «Кризис границ» начинает игру в 1939 году с переделом двух штатов, сменой правительств и двумя войнами.
- В пехотной ветке исследований есть две новые модели винтовок.

## Возможные проблемы
1. **Визуал карты** — procedural colormap/высоты; не арт-финал. Возможны артефакты рек/леса.
2. **Railways** — файл пустой; снабжение через supply_nodes на столицах.
3. **Первый запуск** — смотреть `error.log`; при краше прислать лог.
4. **Кириллический путь мода** — лаунчер может требовать latin junction.
5. Карта **упрощённая** (сетка провинций) — на Этапе 12 можно детализировать берега/ВП.
