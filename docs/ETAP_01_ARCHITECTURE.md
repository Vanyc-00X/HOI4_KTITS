## 3. Предварительный план карты

Компактный вымышленный суперконтинент **Казуалия** + островные/полуостровные зоны.

### Масштаб (целевой)
| Слой | Оценка | Комментарий |
|------|--------|-------------|
| Provinces | **900–1200** | достаточно для фронтов, не перегружает AI |
| States | **110–130** | ~4–7 на среднюю страну; крупные 8–12; малые 3–4 |
| Strategic regions | **24–28** | ≈1 регион на страну + море/буфер |
| Sea zones | **12–16** | кольцо вокруг континента + внутренние моря |
| Air zones | **24–28** | совпадают со strategic regions суши |

### Макрорегионы (расположение стран)

```
        [СЕВЕР: SVA —— CLB —— ART]
              |         |       |
[СЗ: KMS]—[ZLD]—[VCI CORE]—[NBL]—[СВ: ZNS]
              |    |    |    |
         [MUS] [SOY] [FDP] [DMK]
              |    |    |    |
[З: ISL]—[TRF]—[ZML]—[ISG]—[HRL]—[В: KRZ]
              |              |
         [ADL]          [CRE]—[BTR]
              |              |
        [ЮЗ: ZKR]——[SHF]——[ЮВ: KZS]
```

- **Центр силы:** VCI (имперское ядро), окружена буферами SOY / FDP / ZLD / NBL  
- **Красный пояс:** KRZ на востоке, ISG / ZML как идеологические соседи  
- **Тёмный пояс:** BTR + CRE на юго-востоке  
- **Техно-север:** SVA + CLB  
- **Торговый запад/юг:** HRL, KMS, ZKR, ISL  
- **NPC-канон:** KZS (юго-восток), ADL (юго-запад) — полноценные теги, но меньше стартовой мощи  

Столицы (ID states — назначаются на Этапе 3): по одному столичному state на страну + ключевые ресурсные/промышленные.

## 5. Краткий план реализации стран

### Группа A (Этап 5) — VCI, SOY, BTR, KRZ, KZS, MUS
Империя + соседи + красные/чёрные антагонисты + монархия. Приоритет: Индекс Казуальности, НПТ-зачатки, революционный экспорт, Корона↔Парламент.

### Группа B (Этап 6) — TRF, ZLD, ISL, CLB, ADL, DMK
Коммуны, коалиции, модернизация, технократия, дипломатия, интегрализм.

### Группа C (Этап 7) — FDP, CRE, SVA, ART, KMS, ZNS
Парламент, мобилизация, наука, национализм, мягкая сила, пан-регион.

### Группа D (Этап 8) — ZKR, ZML, NBL, ISG, HRL, SHF
Рынок, популизм, перегрев, кооперативы, лига, федерализм.

На каждую страну минимум:
- 4 крупные политические ветки + секретная
- экономика / армия / дипломатия
- фокусы = 21 день
- 8–15 национальных событий
- уникальная механика (variable + ideas/decisions)

## 8. Возможные проблемы

1. **Версия игры** — `supported_version` и формат map/railway зависят от патча; сверить перед Этапом 3.  
2. **replace_path** — при неполной замене history/map игра крашится; на Этапе 2–3 нужен минимальный playable bookmark.  
3. **Кастомные идеологии** — локальные названия ≠ новые ideology groups; на Этапе 2 сабтипы внутри 4 ванильных групп (стабильнее), либо расширение ideologies с риском совместимости.  
4. **Кириллица в путях** — лаунчер Paradox иногда капризничает; при проблемах — junction/symlink латиницей в `Documents\...\mod\`.  
5. **Теги** — VCI/SOY/… не должны пересекаться с другими активными модами; ISL/CLB выбраны вместо ISR/CHL (ванильный конфликт имён).
