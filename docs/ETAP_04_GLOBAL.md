# Этап 4 — Глобальные механики

Версия мода: **0.4.0**

## Системы

### Шкала Абсурда (`global.mk_absurd_temp`, 0–100)
- Старт: 12
- Месячный тик (+1…+3) через `on_monthly` у VCI
- Решения: «Раскачать абсурд» / «Остудить риторику»; отдельные державы могут снижать шкалу самостоятельно
- Пороги → идеи `mk_idea_absurd_*` на всех MK-странах
- ≥40 или дата > 1936.3.11 → **Великий Политический Поворот**
- ≥85 → news `mk_global.5`
- Игровая шкала заменяет для мода политическое значение мирового напряжения; штатный World Tension остаётся техническим параметром движка HOI4

### 24 Голоса Мира
- Переменная страны `mk_world_votes` (старт 1, VCI = 3)
- Лоббирование голосов, созыв Конгресса (стоимость 3 голоса), международный мандат деэскалации (2 голоса)
- Кулдаун Конгресса: 3 месяца (`global.mk_congress_cooldown_months`)
- Сессия: event `mk_global.10`; успешное осуждение санкционирует совместную операцию и снижает Абсурд, провал повышает его. Программа деэскалации даёт всем странам стабильность и временный мандат Конгресса

### НПТ
- Переменная `mk_npt` (SOY/BTR стартуют с 2)
- Решения финансирования и пропаганды
- При `mk_npt > 4` → идея `mk_idea_npt_network`

### Идеологические альянсы + ревизионизм
- Создание фракции по идеологии
- Приглашение единомышленников
- «Обвинить в ревизионизме» → штраф + рост Абсурда
- Лидер блока: «Изгнать ревизиониста» → kick + wargoal

## Как проверить в игре (VCI)
1. После старта — news «Эра Безумных Правителей»
2. Решения → категории Абсурд / Голоса / НПТ / Альянсы
3. «Сводка» показывает переменные
4. Лоббировать голоса → созвать Конгресс
5. После ~70 дней или Абсурд ≥40 — Великий Поворот
